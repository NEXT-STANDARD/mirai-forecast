NEW-9（軽微）— ヘッダーの backdrop-filter がビルドで落ちている

NEW-9軽微・見た目のみ sticky が直ったことで初めて表面化した

ソースには両方が書かれています。

/* src/index.css:227 */ backdrop-filter: blur(20px); -webkit-backdrop-filter: blur(20px);

ところがビルド後の CSS には無印プロパティが残っていません。

.header-container-slim{z-index:40;-webkit-backdrop-filter:blur(20px);background:#020617d9;...}

実測でもヘッダーの backdropFilter は none です。 検証ブラウザ自体は backdrop-filter に対応しています（単体テストで blur(20px) を返す）が、 -webkit- プレフィックス版のみの要素は none になることも確認しました。

結果、background: rgba(2, 6, 23, 0.85) の 15% の透過から、スクロール中の文字が透けます。

影響は見た目だけです。ただし、これまでヘッダーが流れていたため背後に何も来ず、 sticky が直った今回はじめて表面化したものです。

対策：ビルド設定（build.cssTarget など）を見直して無印プロパティを残すか、 background の不透明度を上げる（0.85 → 0.95 程度）ことで実用上は解消します。
