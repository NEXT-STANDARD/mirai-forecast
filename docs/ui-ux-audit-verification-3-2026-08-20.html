最重要：フォーカストラップが入力を破壊している

回帰機能停止 「問いを提案」フォームに1文字も入力できない
実機テスト（本番ビルド） 入力前フォーカス : 入力欄 ✅ 1文字入力（'あ'） 入力後フォーカス : BUTTON.modal-close-btn ❌ 奪われた

フォームは実質的に使用不能です。

さらに、全モーダルで自動的に発生します。 モーダルを開いたまま何も操作せず観測したところ、6秒後に自動でフォーカスが奪われました。

1s 入力欄 6s BUTTON.modal-close-btn ← ユーザー操作なし

原因：src/utils/useFocusTrap.ts の依存配列に onClose が入っています。

useEffect(() => { … const focusables = getFocusableElements(); if (focusables.length > 0) focusables[0].focus(); // ← 毎回ここに戻る … return () => { previousFocusedElement.current?.focus(); }; }, [isOpen, onClose]); // ← onClose が毎回変わる
呼び出し元渡している値再生成のタイミング
ProposeTopicModal.tsx:27() => handleReset()モーダル自身の再レンダーごと＝1キーストロークごと
App.tsx 541/547/559/566/572/581/606() => setXxx(false) × 7App の再レンダーごと＝30秒ポーリングごと

対策

// 1. 依存配列から onClose を外し、ref で保持する const onCloseRef = useRef(onClose); useEffect(() => { onCloseRef.current = onClose; }); useEffect(() => { … }, [isOpen]); // onClose を依存から外す // 2. 併せて呼び出し側を useCallback で安定させる const handleCloseProposeModal = useCallback(() => setIsProposeModalOpen(false), []);

また、初期フォーカスは focusables[0]（＝閉じるボタン）ではなく、 モーダル本体か最初の意味のある操作要素に当てるほうが自然です。

NEW-1：PWA バナーは依然としてフッターリンクを覆っている

NEW-1未解決 余白拡大では解決しない — しかも前回より紛らわしい挙動に

報告：「ルートパディングを pb-36 md:pb-12（144px）へ拡大し、バナー配置を bottom: 5.5rem に最適化。利用規約・プライバシーポリシーのリンクが 100% 確実にクリック可能に。」

実測（本番ビルド・375×812・最下部までスクロール） ルート余白 : 144px ✅ 拡大されている 固定バー高 : 81px PWAバナー : 351x217 top=507 z-index 900（1000から低下） フッターリンク位置 : y 530〜556 ← バナーの範囲 507〜724 に完全に含まれる 利用規約 → 中心のヒット要素: BUTTON.pwa-close-btn ❌ プライバシーポリシー → 中心のヒット要素: BUTTON.pwa-close-btn ❌

余白の拡大はコンテンツを上に押し上げるだけで、 バナーはビューポート下端を基準に配置されているためリンクの上に残り続けます。

しかも前回より悪化しています。 前回はバナー本体が重なっていましたが、 今回はリンク中心が バナーの閉じるボタン（×） と一致します。 つまり「利用規約」をタップすると バナーが閉じるだけ で、規約は開きません。 何かが起きたように見えるぶん、より紛らわしい挙動です。

有効な対策：フッターが画面内に入ったらバナーを非表示にする（IntersectionObserver）、 またはバナーを固定配置ではなくフッター直前のインライン要素にする。余白の拡大では解決しません。

G-3：英語タイトルが 6件 → 16件に増加

G-3悪化 原因はコードではなく Supabase のデータ

前回は日本語だった銘柄まで英語になりました。

Will JD Vance win the 2028 US Presidential Election? ← 旧「JD・ヴァンスは2028年米大統領選挙で勝利するか？」 Will Paris Saint-Germain win the 2026-27 UEFA…? ← 旧「パリ・サンジェルマンは…制覇するか？」 Strait of Hormuz traffic returns to normal by August 31? ← 旧「ホルムズ海峡の通航量は…正常化するか？」 Will Abiy Ahmed be the next Prime Minister of Ethiopia? ← 旧「アビィ・アハメドは次期エチオピア首相に留任するか？」

モバイルの固定投票バーも 🎯 観測中: Will JD Vance win the... と英語です。

Supabase の events テーブルを直接照会しました。

総件数 : 95 title_ja が日本語 : 30 件 (32%) title_ja が英語 : 65 件 (68%) title_ja == title_en : 73 件 ← 翻訳が行われていない行

title_ja フィールドに英語がそのまま格納されています（空ではありません）。 コード側のロジック mapped?.titleJa || db.title_ja || db.title_en は正しく、 db.title_ja に英語が入っている以上それを表示します。

そして TITLE_TRANSLATION_MAP の収録件数は 7件。 65件の英語タイトルに対する被覆率は約 11% です。

対策：翻訳マップの拡充ではなく、同期パイプライン側で title_ja を生成するのが本筋です。
