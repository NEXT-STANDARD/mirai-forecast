全ページ横はみ出しの全数計測（iframe 並列） — ページ単位でナビゲートすると 69回かかるので、同一オリジンの iframe に並べて一括計測しました。 iframe の幅がそのままビューポート幅になるので、メディアクエリも正しく効きます。

// ★ scrollWidth だけを見てはいけない // ルートに overflow-x: clip があるので、はみ出していても scrollWidth === clientWidth になる d.querySelectorAll('*').forEach(e => { const r = e.getBoundingClientRect(); if (r.right > vw + 1 || r.left < -1) { // 意図した横スクロール帯の中は除外する let p = e.parentElement, inScroller = false; while (p) { const o = win.getComputedStyle(p).overflowX; if ((o === 'auto' || o === 'scroll') && p.clientWidth < p.scrollWidth) { inScroller = true; break; } p = p.parentElement; } if (!inScroller) bad.push(e); } });

描画完了の待ち方 — onload は HTML の読み込み完了で、React のレンダリングと データ取得は終わっていません。12枚並列だと 3.5秒待っても未描画のものが出て、 「0件 ＝ 問題なし」と誤読しかけました。.market-detail-container の出現をポーリングする形に変えています。
