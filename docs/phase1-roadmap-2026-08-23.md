## 0. Phase 0 との性質の違い

Phase 0 は**正解が1つに決まる配線作業**でした。動くか動かないかで判定できた。

Phase 1 は違います。**「何と名乗るか」に技術的な正解はありません。**
だから本ロードマップは2つに分けます。

- **§3-A** — Gemini が機械的に実行でき、私が受け入れ基準で検証できる部分
- **§3-B** — 事業者が決める部分（**確定済み**）
- **§3-C** — 決定を受けた記事の仕様

論点A・B は確定したため、**全タスクに着手できます**。

## 1. 調査でわかったこと（実測）

### 1-1. 「賭けられない。ではどうするか」を書いた日本語ページが無い

「Polymarket 日本 使えない 代替」で検索した結果です。

| 上位に出るもの | 書いてあること |
|---|---|
| cryptonews.com/jp | Polymarketの仕組み・違法性 |
| data-engineering.jp | Polymarketとは？日本から使える？ |
| dappsmarket.net | Polymarketの使い方 |
| polymarket101.com | 2026年の対応国一覧 |

**「日本は制限対象」「見られるが賭けられない」までは各所に書かれています。**
一方、**「ではどうするか」を示したページは見つかりませんでした**。
上位はいずれも暗号資産系メディアで、Polymarketの使い方を解説する立場です。
日本の読者の行き先を示していません。

**ここが最大の空白です。** 未来レーダーはその答えそのものです。

### 1-2. ブランド名では見つけてもらえない

「未来レーダー」で検索すると、**ミリ波レーダー市場の産業レポート**が並びます。

```
ミリ波レーダー市場 規模、業界シェア、トレンド、2035年レポート
世界のミリ波レーダー市場調査、規模、シェアと予測、2037年
航空宇宙・防衛向けミリ波レーダー市場レポート
```

「レーダー」が産業調査の巨大なSEO空間に吸われています。
加えて国内競合に**ミライマ**がいて、音が近い。

**結論：ブランド名検索は当面あてにできません。**
テーマ検索（Polymarket / 予測市場）で入ってもらう設計にすべきです。
これは改名の提案ではなく、**流入設計の前提**の話です。

### 1-3. 「見つかる準備はできたが、見つかる理由がない」

Phase 0 で123の銘柄ページがインデックス可能になりました。
ただし中身は自動生成で、構造も文面も似ています。
検索エンジンから見れば**類似ページが123枚**です。

**入口になる「読む価値のある1ページ」がありません。**

### 1-4. 静的ページの description がトップと同一

title と canonical はページ別に正しく出ています。**description だけが全ページ共通**でした。

```
/forecast        title: 予測一覧・マーケット ｜ 未来レーダー          ✅
/rankings        title: 世論スプレッド乖離ランキング ｜ 未来レーダー   ✅
/ai-connector    title: AI連携・WebMCP設定 ｜ 未来レーダー           ✅
  ↑ すべて description は「世界最大の予測市場（Polymarket）の…」で共通  ❌
```

### 1-5. 私の検証の限界（先に明示します）

**検索ボリュームは測れていません。** キーワードツール（Ahrefs 等）は未認証で使えません。
測れたのは「**どんな記事が存在し、誰が上位にいて、何が書かれていないか**」までです。

「Polymarket 日本」が月間何回検索されているかは、私にはわかりません。
需要の**大きさ**ではなく、**空白の所在**を根拠にしたロードマップだと理解してください。

## 3-A. 実行タスク（Gemini・受け入れ基準あり）

### P1-1 静的ページの description を個別化

**現状**：6ページすべてトップと同じ description。

**実装**：`prerender_markets.mjs` の静的ページ処理に、ページ別の description を定義して差し込む。

| ページ | description の方針 |
|---|---|
| `/` | §3-B で決定（決まるまで現状維持） |
| `/forecast` | 一覧できる銘柄の内容と件数 |
| `/rankings` | 世界と日本のズレが大きい順に見られること |
| `/ai-connector` | ClaudeやCursorから予測データを引ける手順 |
| `/developers` | 同上（開発者向け） |
| `/letter-to-mike` | Polymarket日本責任者への公開書簡であること |

**受け入れ基準**：6ページすべてで description が異なり、いずれも120字以内。

---

### P1-2 記事ページの器を作る

**目的**：解説記事を置ける場所が今ありません。

**実装**
- ルーティングに `/guide/:slug` を追加（`App.tsx` の既存パターンに合わせる）
- 記事本文は Markdown またはコンポーネントとして `src/content/guides/` に配置
- `prerender_markets.mjs` を拡張し、**記事ページも `.html` 単独でプリレンダー**する
  - title / description / og:* / canonical（自己参照）／JSON-LD（`Article`）を個別に出力
- sitemap に `/guide/:slug` を含める

**注意点**
- 銘柄ページと同じく **`.html` 単独出力**にすること（ディレクトリ形式を作らない。307が復活します）
- OGP画像は当面 `/ogp-main.png` でよい。記事別画像は後回し

**受け入れ基準**
- `/guide/<slug>` が **HTTP 200**（307ではない）
- `og:title` `description` `canonical` が記事固有
- JSON-LD が `Article` で `JSON.parse` 可能
- sitemap に含まれ、死にURLが増えていないこと

---

### P1-3 内部リンク（記事 ⇄ 銘柄）

**目的**：123枚の銘柄ページを、入口ページの補強に使う。

**実装**
- 記事本文から関連銘柄へリンクできる仕組み（記事側に slug を列挙）
- 銘柄詳細ページに「この銘柄について詳しく」で記事へ戻る導線を1つ

**受け入れ基準**：記事から3件以上の銘柄へリンクがあり、リンク先がすべて200。

## 3-C. 1本目の記事の仕様

**URL**：`/guide/polymarket-japan`（案）
**想定読者**：「Polymarket 日本」「Polymarket 使えない」で検索してきた人

### 構成

| 節 | 内容 |
|---|---|
| 1 | 結論を先に — 見ることはできる。日本から資金を投じることはできない |
| 2 | 何が起きたか — 2026年5月の経緯（下記の事実のみ） |
| 3 | なぜか — 日本の賭博規制の整理（下記の注意を厳守） |
| 4 | ではどうするか — 無料で見る／無料で予測する選択肢。ここで未来レーダーを置く |
| 5 | 今後の見通し — Polymarket自身が2030年の認可を目指していること |

### 使ってよい事実（出典つき・これ以外を断定しない）

| 事実 | 出典 |
|---|---|
| 2026-05-22、Polymarket が日本市場責任者に Mike Eidlin 氏を起用 | Yahoo!ファイナンス／Pacific Meta |
| 目標は **2030年の規制認可** | 同上 |
| 2026年5月下旬、日本を地理制限リストに追加。**閲覧は可・新規注文は不可** | Polymarket101 ほか |
| 賭博罪は刑法185条。構成要件は「偶然の勝敗により**財物又は財産上の利益**の得喪を争う」こと | 条文 |
| 日本で現実的に適法とされるのは**無償・非換金・非譲渡のポイント型**という整理がある | パークス法律事務所の公開記事 |
| 国内には報酬型（ポイ活型）のサービスが複数あり、月間100万人規模の報道がある | Bloomberg 2026-06-29 |

### 厳守事項（法務リスクの回避）

- **法的助言をしない。** 「違法です」「合法です」と自サイトの結論として断定しない
- 法解釈は**必ず出典を明示して引用**する（「パークス法律事務所の整理によれば」）
- 「こうすれば賭けられる」「VPNで回避」等の**回避方法は一切書かない**
- 個別の判断は専門家に相談するよう1行添える
- 競合サービス（ミライマ等）を**貶めない**。事実として並べるだけにする

### 未来レーダーの置き方

売り込みは最終節の1箇所だけにしてください。
「賭けられないが見たい人向けに、日本語で並べて見られるものを作りました」で十分です。
記事の価値は**問いに答えること**であって、誘導ではありません。

### 受け入れ基準

- `/guide/polymarket-japan` が **HTTP 200**（307でない）
- 独自の `title` / `description` / `canonical`（自己参照）／JSON-LD（`Article`）
- 本文から**3件以上の銘柄ページ**へリンクし、すべて200
- sitemap に含まれる
- **上記「使ってよい事実」以外の断定的な法解釈が含まれていないこと**（私が読んで確認します）
