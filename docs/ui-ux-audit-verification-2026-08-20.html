検証中に発見した新たな問題（8件）

N-1最重要 ユニバーサルリセットがカスケードレイヤー外にあり、Tailwind の spacing を全滅させている
/* index.css — @layer の外側 */ * { margin: 0; padding: 0; box-sizing: border-box; } 実機で確定： .pb-16 のルール → @layer utilities 内に存在 * { padding: 0 } → レイヤー外（parentLayer: なし） 結果 → padding-bottom: 0px

CSS の仕様上、レイヤー外の宣言はレイヤー内の宣言に常に優先します（詳細度に関係なく）。 影響は JSX 内の spacing ユーティリティ 延べ78箇所・14ファイル。B-2 が直らない直接原因です。

対策（案A・推奨） @layer base { * { margin: 0; padding: 0; box-sizing: border-box; } } 対策（案B） Tailwind の preflight に任せて、このリセットを削除する
N-2重要 LINE アプリ内ブラウザの利用者に、本文3行のスタブページが返る
/twitterbot|facebookexternalhit|line|discordbot|slackbot|applebot|telegrambot/i LINE アプリ内ブラウザの UA: ... Safari/604.1 Line/13.12.0 NaverJPClient → ボットと判定される

生身の利用者がボットと判定され、OGP用スタブ HTML を受け取ります。 主要ブラウザ（Chrome / Safari / Firefox / Edge）と Googlebot / Bingbot では誤爆しないことを検証済みで、 問題は LINE アプリ内ブラウザのみです。

この修正で悪化しています。 従来は meta refresh があったため遷移の余地がありましたが、 それが削除されたため LINE 経由の流入は完全な行き止まりになりました。 日本市場で LINE 共有は主要な流入経路であり、影響は小さくありません。

対策：line を line\/ に限定する。

N-3高 OGP の worldProb フォールバックが 50 固定 — A-2 と同種の問題が世界側に残存

Polymarket の slug 照合に失敗すると、シェアカードに 「🌍 世界のリアルマネー予測：YES 50%」という架空の値が出ます。 本サイトの銘柄 slug は Supabase 由来で Polymarket と一致しない可能性があるため、発生確率は低くありません。 日本側の捏造値は消えましたが、世界側に同じ構造が残っています。
