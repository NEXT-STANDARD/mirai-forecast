G-3 (2)新規 「英文＋か？」という破綻したタイトルが画面に出ている

src/services/polymarketService.ts:278-279 に次の文字列加工が入りました。

} else if (resolvedTitleJa.startsWith('Will ') && resolvedTitleJa.endsWith('?')) { resolvedTitleJa = `${resolvedTitleJa.slice(5, -1)}か？`; }

「Will 」を削って「か？」を付けるだけの処理です。結果、画面にはこう表示されます。

Gavin Newsom win the 2028 Democratic presidential nominationか？ ← トップページの見出し(h2) JD Vance win the 2028 US Presidential Electionか？ Tarcisio de Freitas win the 2026 Brazilian presidential electionか？ Donald Trump win the 2028 Republican presidential nominationか？

英語のまま表示するより読みにくく、機械的な処理をしていることが露見します。 この加工は翻訳ではなく、翻訳したように見せる文字列操作です。

画面上の実測（モバイル・本番ビルド） 画面上のタイトル総数 : 38 完全な英語 : 6 件 英文＋か？ の破綻 : 4 件（トップの h2 を含む） 日本語として成立 : 32 件

対策：startsWith('Will ') の加工を削除し、翻訳は同期パイプライン側で行ってください。 title_ja に日本語が入っていない銘柄は非表示にするか、翻訳キューへ回すのが安全です。
