## ⚠️ `cssTarget` は、ヘッダーには効いていない

ビルド後の CSS を直接確認しました。

```css
/* dist/assets/index-*.css */
.header-container-slim{z-index:40;-webkit-backdrop-filter:blur(20px);background:#020617f5;...}
                                  ↑ -webkit- のみ。無印は入っていない
```

`cssTarget: 'chrome90'` を外してビルドしても**結果は同じ**でした。

```
cssTarget あり → -webkit-backdrop-filter のみ
cssTarget なし → -webkit-backdrop-filter のみ
```

ただし `cssTarget` が無意味だったわけではありません。
ファイル全体では**無印プロパティが 7 箇所残っています**。効かなかったのはヘッダーを含む特定の2ルールだけです。

### 原因：宣言の順序

`index.css` 内で `backdrop-filter` を持つルールは 7 つあり、
**両方（無印と `-webkit-`）を宣言しているのは 2 つだけ**です。

| ルール | 宣言順 | ビルド後 |
|---|---|---|
| `.header-container-slim`（232行） | 無印 → `-webkit-` | ❌ `-webkit-` のみ |
| モーダル（1829行） | 無印 → `-webkit-` | ❌ `-webkit-` のみ |
| 他5ルール | 無印のみ | ✅ 無印が残る |

esbuild の CSS 最適化は、この2つを同等の宣言として畳み込み、**後に書かれたほうを残します。**
ソースが `無印 → -webkit-` の順なので、標準プロパティが捨てられていました。

### 検証済みの修正：順序を入れ替えるだけ

`-webkit-` を先、無印を後にしてビルドし直しました。

```css
-webkit-backdrop-filter: blur(20px);
backdrop-filter: blur(20px);        /* ← 後に置く */
```

```
結果  →  .header-container-slim{...backdrop-filter:blur(20px)...}   ✅ 無印が残った
        無印プロパティ総数 7 → 9
```

ベンダープレフィックスは**プレフィックス版を先、標準版を後**に書くのが慣例で、その形に直すだけです。
該当は 2 箇所（232-233行 / 1829-1830行）のみです。

> 検証後、`index.css` は `diff` で完全一致を確認して復元しています。
> なお背景が 0.96 になった今、blur が無くても実害は出ていません。急ぐ修正ではありません。

こういうときに効くのが、まさにこのプロジェクトで整備してきた検証の型です。

```
推定で直す → 直ったように見える
実測で確かめる → 直った理由が違うと分かる
```

ビルド後の CSS を1回 grep すれば分かる話でした。
自己検証エンジンに「`.header-container-slim` に無印 `backdrop-filter` が存在すること」を
1行足しておけば、この種の推定違いも自動で拾えます。

`check #8` の精密化は、指摘（過検知の懸念）を正確に受け止めた良い修正でした。
検知力を落とさずに誤検知だけを消しており、**3種のテストすべてで期待どおりに動いています。**

残る3件は構造リファクタリングのみです。とくに `index.css` が 1万行を超えたので、
`B-3` は「いつかやる」から「そろそろやる」に移ってよい頃だと思います。

## 付録：ビルド出力の比較手順

```bash
# cssTarget の有無で出力が変わるかを確かめる
npx vite build
grep -o '\.header-container-slim{[^}]*}' dist/assets/*.css | grep -o '[-a-z]*backdrop-filter'

# 宣言順の入れ替えを試す
# （-webkit- を先、無印を後にして再ビルド）
grep -o '[^-]backdrop-filter:' dist/assets/*.css | wc -l    # 無印の総数を数える
```

破壊テストで行番号を使わない（ファイルが伸びるとずれる）:

```bash
# ✗ 行番号指定は危険
sed -i '' '7527s/clip/hidden/' src/index.css

# ✓ 内容で置換する
python3 -c "
p='src/index.css'; s=open(p).read()
open(p,'w').write(s.replace('overflow-x: clip !important;','overflow-x: hidden !important;'))"
```
