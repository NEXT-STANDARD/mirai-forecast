❌ P1-3 — 内部リンクが「リンク」になっていない

症状

記事から関連銘柄への導線は表示され、クリックもできます。

しかし <a href> ではなく <div> のクリックハンドラで実装されています。

記事ページ /guide/polymarket-japan <a href> の数 : 0 関連銘柄の表示 : ✅ FRB・日銀・GPT-5 の3件が描画されている クリックしたときの挙動 : ✅ /market/fed-decision-in-september-762 へ遷移した

これはサイト全体の実装です。

トップページ <a href> の数 : 0 銘柄カード : 28枚（すべて <div class="market-card-item">） ヘッダーのナビ : すべて <button>

なぜ問題か

P1-3 の目的は「123枚の銘柄ページを、入口ページの補強に使う」ことでした。

そのためには検索エンジンがリンクを辿れる必要があります。

人間 : クリックできる → 問題なし クローラ : リンクが存在しない → 辿れない

現状、銘柄ページは sitemap 経由でしか発見されません。

内部リンクによるクロール優先度・評価の受け渡しがゼロです。

これは Phase 1 で作り込まれたものではなく、SPA の初期からの実装です。

ただし P1-3 の受け入れ基準（「記事から3件以上の銘柄へリンクし、すべて200」）は満たしていません。

チェックが通ってしまった理由

追加された検査は、relatedMarketSlugs のデータ妥当性を見ています。

// 関連記事リンクが有効銘柄に実在すること (P1-3) const relatedMatch = guideSource.match(/relatedMarketSlugs:\s*\[([\s\S]*?)\]/); if (rawSlugs.length < 3) { … } for (const slug of rawSlugs) { activeEvents.some(...) }

**「3件以上あるか」「その slug が実在するか」は見ていますが、

「<a href> として出力されているか」は見ていません。**

チェック名が「内部リンク整合性」なので、実態より広く読めてしまいます。

修正案

主案：銘柄カードとナビを <a href> にする

// 現在 <div className="market-card-item" onClick={() => navigate(slug)}> // 提案 <a href={`/market/${slug}`} className="market-card-item" onClick={(e) => { e.preventDefault(); navigate(slug); }}>

preventDefault + pushState で SPA の挙動は今のまま保てます。

クローラは href を読み、人はSPA遷移する、という両立ができます。

併せて：チェックを実体に合わせる

dist/guide/polymarket-japan.html ではなく、描画後のDOMで

a[href^="/market/"] が3件以上あることを見る必要があります。

プリレンダーHTMLには本文が入らないため、静的検査では不可能です。

補足：影響は記事だけではありません。トップの28枚のカードも同様なので、

修正すればサイト全体の内部リンク構造が一度に立ち上がります。
