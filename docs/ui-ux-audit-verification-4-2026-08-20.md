## ⚠️ NEW-1 — 恒久的な遮蔽は解消、ただし約0.8秒の空白が残る

`IntersectionObserver` が導入され、`ComplianceBanner` に `id="compliance-footer"` が付きました。
フッターが画面に入るとバナーが消えます。**恒久的にリンクが押せない状態は解消しています。**

ただし、**バナーが消えるまでに約0.8秒かかり、その間リンクは押せません。**

```
scroll-behavior: auto（アニメーションなし）で瞬間移動して計測

  ジャンプ直後のフッター top : -133（＝すでに画面内）
   54ms   バナー: 有   リンク判定: pwa-close-btn ❌
  104ms   バナー: 有   リンク判定: pwa-close-btn ❌
  204ms   バナー: 有   リンク判定: pwa-close-btn ❌
  305ms   バナー: 有   リンク判定: pwa-close-btn ❌
  760ms   バナー: 無   リンク判定: リンク ✅

  2回計測: 803ms / 760ms（再現性あり）
```

スクロールを止めてから0.8秒以内にタップすると、**バナーの × が反応して規約は開きません。**
実使用でスクロール停止から0.5〜1秒でタップするのは十分ありうる速度です。

**確実な対策**: `IntersectionObserver` に頼らず、`.compliance-footer` に
バナー高さぶんの `padding-bottom` を常時確保するか、バナーを固定配置ではなく
フッター直前のインライン要素にすれば、タイミングに依存せず解決します。

## ❌ G-3 — 再び悪化。しかも新しい壊れ方をしている

### (1) DB が英語に戻っている

`scripts/translate_all_supabase_events.mjs` が作成され、一度は全件日本語化されました。
検証開始時の照会では **95件中 100% 日本語**でした。

しかし約30分後に再照会したところ：

```
総件数                   : 96   （95 → 96 に増加）
① 完全に英語（日本語ゼロ） : 25 件 (26%)
② 日本語として成立        : 71 件 (74%)
```

同期処理が新しい銘柄を取り込み、**翻訳を経ずに英語のまま `title_ja` に入れています。**
翻訳スクリプトは手動実行の一回きりで、同期パイプラインには組み込まれていません。

英語のまま残っている例：
```
Fed Decision in September?: 50+ bps decrease?
Will Gavin Newsom win the 2028 Democratic presidential nomination?
What price will Ethereum hit in 2026?: ↑ 3,000?
Will Abiy Ahmed be the next Prime Minister of Ethiopia?
```

### (2) 「英文＋か？」という破綻したタイトルが画面に出ている

`src/services/polymarketService.ts:278-279` に、次の文字列加工が入りました。

```js
} else if (resolvedTitleJa.startsWith('Will ') && resolvedTitleJa.endsWith('?')) {
  resolvedTitleJa = `${resolvedTitleJa.slice(5, -1)}か？`;
}
```

「Will 」を削って「か？」を付けるだけの処理です。結果、画面にはこう表示されます。

```
Gavin Newsom win the 2028 Democratic presidential nominationか？   ← トップページの見出し(h2)
JD Vance win the 2028 US Presidential Electionか？
Tarcisio de Freitas win the 2026 Brazilian presidential electionか？
Donald Trump win the 2028 Republican presidential nominationか？
```

**英語のまま表示するより読みにくく、機械的な処理をしていることが露見します。**
この加工は翻訳ではなく、翻訳したように見せる文字列操作です。

### 画面上の実測（モバイル・本番ビルド）

```
画面上のタイトル総数     : 38
完全な英語              :  6 件
英文＋か？ の破綻        :  4 件（トップの h2 を含む）
日本語として成立         : 32 件
```

**対策**: `startsWith('Will ')` の加工を削除し、翻訳は同期パイプライン側で行ってください。
`title_ja` に日本語が入っていない銘柄は非表示にするか、翻訳キューへ回すのが安全です。

## 所感

**フォーカストラップの修正は、指摘した内容を正確に読み取って直されていました。**
`onCloseRef` パターン、`isAlreadyInside` ガード、`requestAnimationFrame` での再確認まで含めて、
実装として過不足がありません。4ラウンドを通じて最も質の高い修正でした。

一方、G-3 は「データの問題」を「表示の問題」として扱おうとして、かえって悪化しました。
翻訳スクリプトを書いたのは正しい判断ですが、**それを一度手で流しただけでは、
同期が走るたびに元に戻ります。** パイプラインに組み込むまでが修正です。

`Will → か？` の加工も同じ構図で、根本原因（DBに英語が入る）を放置したまま
見た目だけを繕おうとした結果、より悪い見た目になりました。

そして今回、**私自身の第3回の計測も同じ罠にはまっていました。**
「日本語文字が1文字でもあれば日本語」という雑な判定で「英語0件」と報告してしまい、
実際にはトップページの見出しが壊れていました。指摘する側も同じ注意が要ります。
