## ⚠️ サニタイズ処理は「置換表」であって「バリデーション」ではない

第5回で「現在日付より前のカタリストを除外するバリデーション」を提案しました。
実装されたのは `sanitizeText()` という**文字列置換関数**です。

```js
.replace(/2024年11月5日\s*米大統領選.*?（.*?）/g, '2028年11月 米大統領選挙（民主党・共和党決戦）')
...（私が報告した文字列そのものへの個別対応が10件）...
.replace(/2024年/g, '2026年')      // ← 包括ルール
.replace(/2025年/g, '2026年後半');  // ← 包括ルール
```

包括ルールがあるぶん、前回よりは堅牢です。ただし次の穴があります。

| 入力 | 変換結果 | 判定（2026-08-20 基準） |
|---|---|---|
| `2024年3月 FOMC会合` | `2026年3月 FOMC会合` | **まだ過去** |
| `2025年1月 決算発表` | `2026年後半1月 決算発表` | **文字列が破損** |
| `3月中旬公表：連合「春闘…」` | 変換されず | 年がないため判定不能 |
| `2026年2月 日銀会合` | 変換されず | **まだ過去** |

- **日付の妥当性を検証していません。** 年を機械的に +2 しているだけで、「今より前か」を見ていません。
- **現在年が 2026 とハードコードされています。** 2027年になれば、この関数自体が過去日付を生成します。
- `2025年1月` → `2026年後半1月` は日本語として壊れます（現時点では該当データがなく顕在化していません）。

**推奨**：置換ではなく、生成結果を捨てる方向の検証にしてください。

```js
// 例：現在日付より前のカタリストは採用しない
const now = new Date();
const isFuture = (s) => {
  const m = s.match(/(20\d{2})年\s*(\d{1,2})?月/);
  if (!m) return true;                       // 年がなければ判定保留
  const d = new Date(+m[1], (m[2] ? +m[2] : 12) - 1);
  return d >= new Date(now.getFullYear(), now.getMonth());
};
keyCatalysts = (item.keyCatalysts || []).filter(isFuture);
```

## 🆕 検証中に見つかった新たな問題（2件）

### NEW-4 【重要】締切が過ぎたマーケット27件が「投票受付中」のまま表示されている

Supabase の `is_active=true` かつ `end_date` が過去の銘柄が **96件中27件（28%）**あります。
画面上でも投票ボタンが有効なまま表示されています。

```
2026-08-18  ビットコイン価格は8月18日に54,000ドルを上回るか？    （2日前に確定済み）
2026-08-17  ビットコイン価格：8月17日の目標価格水準予測         （3日前）
2026-08-17  イーロン・マスクは8月15日〜17日に何回ポストするか？   （3日前）
2026-08-18  米フロリダ州知事選：共和党予備選で勝利する候補は？    （2日前）
2026-08-16  LoL公式戦: Weibo Gaming vs Invictus Gaming        （4日前）
2026-07-18  イスラエル・イラン間の停戦合意は継続するか？          （1ヶ月前）
```

**すでに결果が出ている事象に対して、利用者が「予報」として投票できる状態です。**
的中判定を売りにしているサイトとして、これは A群（データの誠実性）と同じ性質の問題です。

**対策**：同期時に `end_date < now` の銘柄を `is_active=false` にする、
または表示側で「受付終了」として投票ボタンを無効化してください。

### NEW-5 カードの締切表示が年を落としている

`AllMarketsGrid.tsx:305-310` が `MM/DD` 形式で表示しており、年が消えます。

```js
const datePart = raw.split('T')[0];
const [, m, d] = datePart.split('-');
return `${m}/${d}`;          // ← 年を捨てている
```

締切が2027年以降の銘柄が **9件**あり、いずれも年が見えません。

```
2027-05-30  イングランド・プレミアリーグ 2026-27 優勝クラブ予測  → 表示「05/30」
2028-11-07  ギャビン・ニューサムは2028年民主党大統領候補指名…    → 表示「11/07」
2027-01-01  イーサリアムは2026年までに3,000ドルへ到達するか？    → 表示「01/01」
2028-11-07  JD・バンスは2028年米大統領選挙で勝利を収めるか？     → 表示「11/07」
```

**「05/30」が今年の5月なのか2027年5月なのか区別できません。** NEW-4 と重なると、
利用者は「締切切れの銘柄」と「2年先の銘柄」を見分けられません。

**対策**：年をまたぐ銘柄は `2027/05/30` のように年を含めるか、`あと◯日` の相対表示にしてください。
