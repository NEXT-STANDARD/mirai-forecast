### 実票がある銘柄と突き合わせた

そのうち4銘柄で、詳細ページと埋め込みを並べて確認しました。

| slug | 詳細ページ | 埋め込みウィジェット |

**同じ銘柄で、票数が 4 と 0 に割れています。**

### 原因：投票の集計は別関数で、埋め込みが呼んでいない

```js
// polymarketService.ts:346 — fetchLivePolymarketMarkets() の返り値
japanVotes: { yes: 0, no: 0, total: 0, percentYes: 50 },   // ← 常にゼロ

// polymarketService.ts:367 — 実票はこちらが付与する
export async function syncVotesFromSupabase(items) { … }
```

本体は `App.tsx:279` で `syncVotesFromSupabase(baseItems)` を通していますが、
`EmbedWidgetPage.tsx` は `fetchLivePolymarketMarkets()` だけを呼んで終わっています。

結果として、**ウィジェットの主目的である「世論スプレッド」が 69/69 で一度も表示されません。**
埋め込み先の記事に出るのは、常に「サンプル収集中 (n=0)」です。

### 修正は1行

```js
const events = await fetchLivePolymarketMarkets();
const match = events.find(…);
if (match) {
  const [withVotes] = await syncVotesFromSupabase([match]);   // ← これを通す
  setItem(withVotes);
}
```

> **評価としては**：捏造された数字が消えたことのほうが、票数がゼロで出ることよりはるかに重要です。
> 第14回で「外部の記事に貼られた数字は取り消せない」と書いた懸念は解消されました。
> 残りは配線がもう一段足りないだけです。
