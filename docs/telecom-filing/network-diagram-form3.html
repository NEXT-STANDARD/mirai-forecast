■ 構成及び通信手順の説明

  1. 利用形態：利用者が端末（PC/スマホ）のWebブラウザからインターネット経由で「未来レーダー（https://mirairadar.com）」にアクセスし、各予測銘柄に対して世論投票およびコメントを投稿します。
  2. 通信暗号化：すべての通信はHTTPS/TLS暗号化プロトコル（標準ポート443）を用いて安全に暗号化通信が行われます。
  3. データ管理：投稿されたコメントおよび世論データは、クラウドAPI/データベースサーバー（Supabase / AWS東京データセンター）に蓄積・保管されます。
  4. 公衆配信（掲示板役務）：蓄積された投票集計結果およびコメント情報は、インターネット網を介して他の不特定多数の閲覧利用者に対してWebコンテンツとしてリアルタイム配信（公衆送信）されます。
  5. 設備の非設置：当社は物理的な自前回線設備を保有せず、Cloudflare, Inc. および Supabase, Inc. が提供するクラウドサービスを利用して役務を提供します。
上記のとおり相違ありません。
