## ✅ 307 リダイレクトの根絶

プリレンダーが **`.html` 単独出力**になり、ディレクトリ形式が消えました。

```
dist/market/*.html      : 123件
dist/market/<dir>/      :   0件   ← 前回は123件あり、これが307の原因だった
```

その結果、**リダイレクトの向きが逆転**しました。

| URL | 前回 | 今回 |
|---|---|---|
| `/market/<slug>` | 307 → スラッシュ付きへ | **200** ✅ |
| `/market/<slug>/` | 200 | 307 → **正規形へ** ✅ |
| `/market/<slug>.html` | 307 → スラッシュ付きへ | 307 → **正規形へ** ✅ |

**すべてが1つの正規URLに集約される、正しい形**になりました。

sitemap 全136URLのHTTPステータスも測り直しました。

```
前回 : 200が8件 / 307が125件
今回 : 200が136件 / 307が0件      ← 全件が直接200
```

canonical・og:url・sitemap が宣言する「スラッシュなし」と、実際に200を返すURLが**完全に一致**しました。
