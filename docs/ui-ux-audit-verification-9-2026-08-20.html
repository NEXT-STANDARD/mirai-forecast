NEW-6 — A-3 の是正が AllMarketsGrid に適用されていない

NEW-6高 同じ画面の2箇所で、乖離の基準が違う
// SpreadRankingSection.tsx:36 — A-3 で修正済み const pool = events.filter(ev => ev.japanVotes.total >= 3); // 3票以上に限定 // カードには n=3 / n=5 と票数を併記 ✅ // AllMarketsGrid.tsx:184 — 未修正 const hasGap = event.japanVotes.total > 0 && gap >= 10; // 1票でも表示 // 票数の表示なし ❌

実データでの影響

投票のある銘柄 : 23 1票 : 9銘柄 2票 : 7銘柄 ← 計16銘柄（70%）が3票未満 3票 : 4銘柄 4票 : 2銘柄 5票 : 1銘柄

画面上、7枚のカードに「◯% 乖離」バッジが出ており、いずれも票数の表示がありません。

ビットコインは8月中に100,000ドルに到達するか？ 世界 1% 「49% 乖離」 日本(ロック中) 米FRB：9月FOMCで50bp以上の大幅利下げを実施するか？ 世界 1% 「49% 乖離」 日本(ロック中) パリ・サンジェルマンは2026-27 UEFAチャンピオンズ… 世界 14% 「86% 乖離」 日本(ロック中)

3行目の「86% 乖離」は、ランキング側では n=3 と併記されている同じ銘柄です。 同じ数字が、同じ画面の別セクションでは票数つき、カードでは票数なしで出ています。

さらに、日本世論の数値自体は「🔒 投票で解禁」で伏せられているのに、 乖離バッジからは日本側の値（50%や100%）が逆算できます。バイアス回避というゲートの設計意図とも矛盾します。

対策：AllMarketsGrid の hasGap を japanVotes.total >= 3 に揃え、バッジに n=◯ を併記してください。 SpreadRankingSection と同じ1行の変更です。
