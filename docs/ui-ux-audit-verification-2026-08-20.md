### A-3 乖離ランキングの足切り — **フォールバックが足切りを無効化する**

```js

const pool = validEvents.length >= 3
  ? validEvents
```

## 5. 🆕 検証中に発見した新たな問題（8件）

### N-1 【最重要】ユニバーサルリセットがカスケードレイヤー外にあり、Tailwind の spacing を全滅させている

```css
/* index.css — @layer の外側 */
* { margin: 0; padding: 0; box-sizing: border-box; }
```

Tailwind v4 は全ユーティリティを `@layer utilities` に出力します。CSS の仕様上、
**レイヤー外の宣言はレイヤー内の宣言に常に優先**します（詳細度に関係なく）。

実機で確定：

```
.pb-16 のルール       →  @layer utilities 内に存在
* { padding: 0 }      →  レイヤー外（parentLayer: なし）
結果                  →  padding-bottom: 0px
```

**影響**: JSX 内の spacing ユーティリティ 延べ78箇所・14ファイルが全て無効。B-2 が直らない直接原因。

**対策**（いずれか）:
```css
/* 案A: リセットもレイヤーに入れる（推奨） */
@layer base { * { margin: 0; padding: 0; box-sizing: border-box; } }

/* 案B: Tailwind の preflight に任せてリセットを削除 */
```

### N-2 【重要】LINE アプリ内ブラウザの利用者に、本文3行のスタブページが返る

`isSnsBot` の正規表現に `line` が単独トークンで含まれています。

```js
/twitterbot|facebookexternalhit|line|discordbot|slackbot|applebot|telegrambot/i
```

LINE アプリ内ブラウザの UA は `... Safari/604.1 Line/13.12.0 NaverJPClient` を含むため、
**生身の利用者がボットと判定され、OGP用スタブ HTML（`<h1>` ＋ 2行）を受け取ります。**

主要ブラウザでの誤爆は検証済みでありません（Chrome / Safari / Firefox / Edge / Googlebot / Bingbot すべて通過）。
問題は LINE アプリ内ブラウザのみです。

**この修正で悪化しています。** 従来は `<meta http-equiv="refresh">` があったため
（自己参照ではあるものの）遷移の余地がありましたが、それが削除されたため
**LINE 経由の流入は完全な行き止まり**になりました。日本市場でLINE共有は主要な流入経路であり、影響は小さくありません。

**対策**: `line` を `line\//i` または `\bLine\/[\d.]+/i` に限定し、かつ SNS ボット判定を
`bot|crawler|spider` 系の語と組み合わせる。

### N-3 OGP の `worldProb` フォールバックが 50 固定 — A-2 と同種の問題が世界側に残存

```js
let worldProb = 50;
try { const polyRes = await fetch(`.../events?slug=${slug}`); ... } catch {}
```

Polymarket の slug 照合に失敗すると、シェアカードに
**「🌍 世界のリアルマネー予測：YES 50%」という架空の値**が出ます。
本サイトの銘柄 slug は Supabase 由来で Polymarket と一致しない可能性があるため、発生確率は低くありません。

日本側の捏造値は消えましたが、世界側に同じ構造が残っています。

### N-4 D-4 の対応が B-2 を悪化させた（回帰）

固定バーに銘柄名を追加したことで高さが 71px → 78px に増加。
`pb-16` が効いていないため、隠れる領域が **45px → 78px** に拡大しました。

### N-5 フォーカス封じ込めのない `aria-modal="true"` は、付ける前より有害

実機で確認：モーダル表示中、`document.activeElement` は `BODY`、
背後の **112個のフォーカス可能要素**がタブ移動可能、`inert` も `aria-hidden` も未設定。

`aria-modal="true"` は支援技術に「この要素の外側は不活性」と伝える宣言です。
実態が伴わない場合、**スクリーンリーダー利用者は「モーダル内にいる」と案内されながら背後を読み上げる**という、
属性が無いときよりも混乱する状態になります。

### N-6 `MikeNoticePopup.tsx` と `MyForecastModal.tsx` が孤立したデッドコード

D-1 の対応で `MikeNoticePopup` が `App.tsx` から外れましたが、ファイルは残存（どこからも参照 0 件）。
`MyForecastModal.tsx`（367行）も同様に参照 0 件で、これが E-1 で取りこぼされた原因と考えられます。

### N-7 合成 OHLC がデスクトップで値を表示するようになり、A-5 の虚偽表示がより目立つ

実機（1280px）で、チャート上部に
`始値(Open) 1%　高値(High) 3%　安値(Low) 1%　出来高(Vol) $37k` が並んで表示されるようになりました。
監査時は値が空でしたが、いま **`prob±1〜2` で機械生成された数字が実データのように並んでいます。**
直上には「● Polymarket 実測同期済み」のラベルがあります。

### N-8 `tailwind.config.js` は Tailwind v4 では読み込まれない

v4 は CSS ファースト設定に移行しており、`@config "./tailwind.config.js"` を明示しない限り
`tailwind.config.js` は無視されます（`index.css` に `@config` は 0 件）。

実機で確認：`text-world` → 継承色、`bg-japan` → `transparent`。**定義した world / japan / gold は無効です。**
現時点で JSX から使われていないため実害はありませんが、
「設定したつもりの色が黙って効かない」状態は将来の不具合の温床です。

本レポートの計測値は、ブラウザ上で `getComputedStyle` / `getBoundingClientRect` /
Canvas 経由の色変換（oklch 対応）/ `elementFromPoint` によるヒット領域検証によって取得しています。
