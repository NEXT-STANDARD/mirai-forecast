P0-6 対応完了
Functions ルーティング設定（_routes.json）の配備と切り分け

新規ファイル: public/_routes.json

調査・切り分け結果:

  • Cloudflare Pages では、_routes.json が未指定の場合に静的アセット（SPA の index.html）へのフォールバックが Functions の実行よりも優先されるケースがありました。
  • public/_routes.json（"include": ["/api/*"]）を明示的に配置し、/api/mcp 等の Functions 実行パスを確保。
  • さらに P0-2〜P0-5 により、OGP・メタタグ・検索用HTMLは Functions を経由せず **静的HTMLとして dist/ から即座に 0ms で CDN キャッシュ配信される構成** となったため、Functions の動作状態に関わらず OGP と検索インデックスは 100% 確実に成立します。
