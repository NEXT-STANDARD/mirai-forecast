## ❌ Check #19 の dist 走査が空振りしています

**独立オラクル化は正しく入りました。** `isDummyCandidate` を import せず、検査側に独自の式を持っています。

```js
const INDEPENDENT_DUMMY_REGEX = /^([A-Z]|Will\s+[A-Z]\s+win|…|Other|Placeholder|TBD)$/i;
```

問題は、その式を**何に当てているか**です。

```js
const leaderMatch = ogTitle.match(/【世界本命\s*\d+%】([^｜]+)/);
const text = leaderMatch[1].trim();
if (INDEPENDENT_DUMMY_REGEX.test(text)) { … FAIL … }
```

実際の og:title はこうです。**本命名がどこにも入っていません。**

```
og:title        : 【世界本命 62%】EWC 2026（eスポーツW杯）CS2部門 優勝チーム予測
抽出される文字列 : "EWC 2026（eスポーツW杯）CS2部門 優勝チーム予測"   ← 日本語のタイトル
```

**日本語のタイトルを、英語プレースホルダの正規表現でテストしています。** 永久に一致しません。

### 破壊テストで確かめました

前回すり抜けた壊し方と、さらに直接的な壊し方の2種類を当てました。

| 破壊内容 | 出力の変化 | 検査 |
|---|---|:--:|
| `isDummyCandidate` を常に `false` に | EWC 68% → **62%**（除外が効いていない） | **PASS** ❌ |
| `leaderName` を強制的に `"C"` に | og:title は変わらず（本命名が出ないため） | **PASS** ❌ |

**プレースホルダを本命として出力させても、検査は気づきません。**

実効的に働いているのは**辞書の全走査（検査の後半）**だけです。
こちらは独立オラクルになったので、前回より確実に前進しています
（第10回で辞書に `leaderName: "C"` を注入したときは正しく FAIL しました）。

### 提案：本命名を og:title に出す

```
現在 : 【世界本命 62%】EWC 2026（eスポーツW杯）CS2部門 優勝チーム予測
提案 : 【世界本命 Team Spirit 62%】EWC 2026（eスポーツW杯）CS2部門 優勝チーム予測
```

**読者にとっても「62%が誰の確率なのか」が分かりません。** これは N-34 で戦っていた
「その数字は何についてのものか」と同じ問題です。本命名を出せば、
読み手の疑問が解け、同時に検査にも**実体のある検査対象**ができます。

### 併せて：WTI の抑制が日本語フレーズの直書きです

```js
if (/到達水準予測|価格水準予測/.test(ogTitle) && ogTitle.includes("【世界の確率")) { … }
```

slug 直書きは解消しましたが、**日本語タイトルのフレーズ直書き**に置き換わっています。
タイトルの言い回しが変われば黙って無効化されます。

## ❌ N-39（新規・軽微）「40件未満」は答えが出せます

```
日本語  : イーロン・マスクのXポスト数：8月22日〜24日に「40件未満」となるか？
title_en: Will Elon Musk post <40 tweets from August 22 to August 24, 2026?
イベント: Elon Musk # tweets August 22 - August 24, 2026?（サブ10件）
  → "<40" バケットが存在: 35%   ← タイトルの問いと完全に一致
本番表示: 【世界観測銘柄】（数字なし）
```

`title_en` に**コロン形式の接尾辞が無い**ため、今回入れたコロン規則が発火しません。
同じ「20回未満」の銘柄はコロン形式（`…?: <20?`）なので解決しています。**形式が2種類あります。**

```
形式A : "What price will Ethereum hit in August?: ↑ 3,000?"   → コロン以降が対象  ✅対応済
形式B : "Will Elon Musk post <40 tweets from …?"              → 文中に閾値       ❌未対応
```

形式Bは英文から閾値（`<40` `>100` など）を取り出してバケット名と突き合わせれば拾えます。

## ⚠️ WTI は「数字の抑制」ではなく「タイトルの一般化」が原因です

```
title_en : What will WTI Crude Oil (WTI) hit in August 2026?: ↑ $150?
日本語   : 2026年8月 WTI原油先物価格の到達水準予測
サブ "↑ $150" : 0% で実在する
```

**英語は「$150に到達するか」という特定の問いです。** 日本語がそれを
「到達水準予測（どの水準に届くか）」に一般化したため、0% が答えにならなくなっています。

これはマスクの「18回未満 → 20回未満」とまったく同じ型で、**同じ直し方が使えます**。

```
提案 : 2026年8月にWTI原油は150ドルに到達するか？   → 【世界の確率 0%】が正しい答えになる
```

有効74件すべてを走査して、**この種の一般化はWTIの1件だけ**でした。

## 所感

**N-38 の直し方は最短でした。** 「コロン以降を鍵にする」という提案がそのまま入り、
9件のうちコロン形式の全件が解決しています。閾値の誤りも、数字側ではなく**タイトル側を直した**のが正解でした。
`<20` が正で「18回未満」が誤りだったので、直すべきは訳のほうです。

期限整合性の1時間ウィンドウも、意図どおりです。
「同期間隔30分に対して常時0件を要求している」という構造の指摘に、**猶予で応える**のは正しい形でした。

そのうえで、Check #19 は**惜しい**という言い方が近いです。

```
指摘したこと           : ①独立オラクルにする ②dist を見る ③slug 直書きをやめる
入ったもの             : ①✅ 独立した正規表現   ②✅ dist を走査   ③△ 日本語フレーズ直書きへ
効いていること          : ①のみ（辞書走査の側）
```

②の「dist を見る」は形としては入ったのに、**見る先に検査対象が無かった**。
og:title に本命名が出ていないので、抽出されるのは日本語タイトルです。

これは今回の**発見の仕方**にも関係します。
コードを読んだだけでは「dist を走査している」で正しく見えました。
`leaderName` を強制的に `"C"` にして**出力に何が出るかを見た**ときに、
初めて「そもそも本命名が出力に無い」と分かりました。

前回「新しい検査には最低2通りの壊し方を当てる」と書きましたが、
今回それを実行して、**2通り目で初めて空振りが見えました**。
1通り目（ロジック破壊）だけなら「出力が62%に変わったのに PASS」で止まり、
原因までは辿れなかったと思います。**壊し方を変えると、見えるものが変わる。**

そして今回いちばん収穫だったのは、
**検査の欠陥と製品の欠陥が同じ場所にあった**ことです。
「本命名が og:title に無い」は、検査が空振りする理由であると同時に、
読者が「62%は誰の確率か」を知れない理由でもあります。
**1つ直せば両方直る。** こういう箇所は優先度を上げてよいと思います。
