## 所感

**今回の修正は、これまでで最も筋が良いものでした。**

G-3 は「表示で繕う」のをやめて同期パイプラインに翻訳を組み込み、`title_en` に原文を残しました。
NEW-1 は IntersectionObserver というタイミング依存の仕組みに頼らず、CSS の余白で幾何的に解決しました。
どちらも、指摘した「根本原因に手を入れる」という方向を正確に取っています。

一方で、**A-6 の回帰は 5ラウンドを通じて繰り返されているパターンそのものです。**
G-3 を直すために走らせたスクリプトが、A-6 の修正結果を上書きしました。

データを生成するスクリプトが複数あり、それぞれが別々のタイミングで同じファイルを書き換えるため、
**「直した項目が、別の項目を直したときに戻る」**という状態になっています。

生成スクリプト側にバリデーション（過去日付を弾く、文言を統一する）を1つ入れるだけで、
この往復は止まります。個別に直し続けるより、そこに1回投資するほうが早いはずです。
